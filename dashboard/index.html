Metric contract

FID: rounded uint8 images, pinned LTH14 torch-fidelity Inception features in FP32 with TF32 disabled, and the JiT ImageNet-256 real reference. FDr⁵: a separate frozen evaluator on float images, using normalized Inception (ADM), DINOv2, ViT-MAE, SigLIP, and CLIP distances; ConvNeXt is excluded.

The three seeds resample one checkpoint per model; they are not training replicates. JiT-H uses 198 actual guided network calls (200 by paper convention). Training compute excludes evaluation. This table supersedes older dashboard headline values.
